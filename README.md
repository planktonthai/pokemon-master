# 寶可夢卡牌訓練營

給小學 3～6 年級的寶可夢卡牌遊戲（PTCG）教學網站。在 3D 冒險地圖上一關一關前進，看動畫學規則、玩小遊戲、答題拿星星，最後和電腦來一場接近正式規則的對戰。

👉 **網站：<https://planktonthai.github.io/pokemon-master/>**

## 內容

| 區域 | 關卡 | 學會什麼 |
| --- | --- | --- |
| 🌱 新手草原 | 1～4 關 | 三種卡牌、卡片資訊、場地區域、開局準備、回合流程 |
| 🏜️ 進階山谷 | 5～8 關 | 傷害計算（弱點、抗性）、進化、特殊狀態、獲勝條件 |
| 🌋 高手火山 | 9～10 關＋模擬對戰 | 組牌規則、回合規劃與策略、完整規則實戰 |
| 👑 終極魔王關 | 5 場挑戰 | 由弱到強的五位電腦對手（D1～D5） |

另外還有成就頁（徽章、戰績、可列印的結業證書）、給家長與老師的學習進度報告、新手引導，以及原創的背景音樂與音效。

## 特色

- 純靜態網站（HTML、CSS、JavaScript），不需要伺服器、不用註冊、沒有廣告、不蒐集個人資料。
- 學習進度只存在瀏覽器的 localStorage。
- 3D 效果使用 [Three.js](https://threejs.org/)；沒有硬體加速的裝置會自動改用平面版。
- 玩過一次後可以離線使用（Service Worker）。
- 支援鍵盤操作、螢幕閱讀器與「減少動態效果」設定。

## 資料夾

```
index.html          首頁（3D 世界地圖）
map.html            平面版地圖（沒有 3D 時使用）
units/              10 個教學單元、模擬對戰、終極魔王關
achievements.html   成就與證書
about.html          關於本站、學習進度報告
404.html            找不到頁面
sw.js               離線快取
assets/             樣式、程式、音樂音效、字型、圖片
prototype/          設計初期的風格原型（網站沒有連結到這裡）
```

## 更新網站

1. 修改檔案後推送到 `main` 分支，GitHub Pages 會在 1～3 分鐘內自動更新。
2. 程式和樣式的網址帶有版本號（`?v=`），由建置工具依檔案內容自動產生；網站更新後，玩家下次開啟就會拿到整套新版。
